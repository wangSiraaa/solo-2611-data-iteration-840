虚构社团理事会选举的排序选票勘误与转移票复核（`materials/ballots`）。全部为虚构资料。
共 12 张稳定原票。甲、乙两名录入员各自抄录，且故意落到不同案卷（K1/K2…）。
同一稳定原票即使两稿分属不同案卷也只算一次；只有整理后的有效序列相同才采入。

勘误后（effective）的七张票：4×A>C，2×B，1×C。
- 两票选两人、起初有第一选择的票数 N=7，当选额 floor(7/3)+1 = 3。
- 原抄本（两稿一致 A>B）下 A、B 当选；
- 勘正后优先序 A,C,B 时 A 先当选，4 张票各转 1/4（共 1）给 C，C 达 3 当选；
  票 O5/O6 属 B，B 淘汰时无后继而耗尽 2。
- 同一份勘正选票改用优先序 A,B,C 时，B 以优先序胜出。

同名次票：O8 第二格含两人，整理到该格之前截止，两稿均为 A。
重复名票：O9 中 A 再次单独出现被忽略，有效序列 A>C。
空序列：O12 两稿均为空，保留为有效空序列（不产生第一选择）。
争议票 O10：两稿 A>B 与 A>C 不同；裁决 rev1=A>B 可复查，rev2=A>C 采入。
争议票 O11：两稿不同且裁决作废。
